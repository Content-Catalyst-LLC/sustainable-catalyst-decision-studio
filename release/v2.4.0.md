# Decision Studio v2.4.0 — Uncertainty, Sensitivity & Confidence

Release date: 2026-09-11

## Adds

- Uncertainty Register 1.0
- Sensitivity Analysis 1.0
- Confidence Assessment 1.0
- deterministic weight perturbation
- evaluation-bound sensitivity
- alternative score envelopes
- pairwise overlap diagnostics
- ordering-change visibility
- process-confidence dimensions and limiting factors
- Decision Object / Decision Packet projection
- WordPress workspace and REST parity

## Preserves

- v2.3.1 Criteria, Alternatives & Tradeoff Matrix
- v2.3.0 Energy Systems Runtime Consumer
- v2.2.0 Evidence & Source Bundles
- v2.1.0 Unified Decision Object
- Decision Packet 2.0 and all earlier connected-platform capabilities

## Boundaries

No automatic winner selection. No automatic recommendation. Process confidence is not a probability of correctness. Sensitivity analysis is not forecasting or assurance.
