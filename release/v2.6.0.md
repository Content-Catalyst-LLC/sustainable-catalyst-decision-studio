# Decision Studio v2.6.0 — Lab + Workbench Native Handoffs

Release date: 2026-09-13  
Build fingerprint: `scds-v2.6.0-lab-workbench-native-handoffs`  
Source commit identity: `release-v2.6.0`

## Added

- First-class Research Lab analysis handoffs.
- First-class Workbench computation handoffs.
- Bounded Decision Studio → Lab/Workbench analysis/computation requests.
- Handoff receipts that separate transport acceptance from validation/approval.
- Deterministic SHA-256 artifact and request fingerprints.
- Tamper detection for returned or replayed artifacts.
- Request/return lineage through `request_id`.
- Unified Decision Object and Decision Packet attachment.
- WordPress **Lab + Workbench Handoffs** workspace and REST parity.

## Preserved

- v2.5.0 Scenario Comparison & Stress Testing.
- v2.4.0 Uncertainty, Sensitivity & Confidence.
- v2.3.1 Criteria, Alternatives & Tradeoff Matrix.
- Energy Runtime Consumer v2.3.0 and its target-side contract.
- v2.2 Evidence & Source Bundles and v2.1 Unified Decision Object.
- Decision Packet `scds-decision-packet/2.0` with no breaking migration.

## Boundary

Decision Studio receives and reasons over source-owned artifacts. It does not run Lab experiments, execute Workbench computation, infer that receipt means validation, or automatically choose/recommend an alternative.
