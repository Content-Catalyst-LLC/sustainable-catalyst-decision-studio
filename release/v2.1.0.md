# Decision Studio v2.1.0 — Unified Decision Object Model & Platform Context Foundation

## Included

- `scds-decision-object/1.0` first-class decision schema.
- `scds-platform-context/1.0` cross-product context registry.
- Deterministic Decision Packet → Decision Object promotion.
- Reversible Decision Object → Decision Packet projection that preserves unknown packet fields through the retained source packet.
- Provenance fingerprints and platform artifact-link fingerprints.
- Core completeness diagnostics for question, alternatives, criteria, evidence, assumptions, recommendation, and provenance.
- Seven new FastAPI routes and matching WordPress REST parity.
- New WordPress **Decision Object** tab and `mode="decision-object"` surface.
- Release contracts, samples, integration manifest, regression tests, documentation, and packaging updates.
- v2.0.1 Catalyst module navigation and v2.0.0 Connected Platform preserved.
