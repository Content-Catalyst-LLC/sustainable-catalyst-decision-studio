# Decision Studio v2.3.1 — Criteria, Alternatives & Tradeoff Matrix

Released 2026-09-11.

## Added

- First-class Criteria Set, Alternatives Set, Tradeoff Matrix, and Tradeoff Diagnostics schemas.
- Normalized criteria weights while preserving input weights.
- Direct or scale-derived comparison scores.
- Matrix coverage, missing-cell, review, unknown-ID, unscored-cell, and threshold diagnostics.
- Weighted alternative summaries with explicit no-auto-recommendation language.
- Unified Decision Object attachment and Decision Packet projection.
- WordPress Tradeoff Matrix workspace and REST parity.
- Contabo/Docker v2.3.1 runtime identity.

## Preserved

- Evidence & Source Bundles 1.0.
- Unified Decision Object 1.0.
- Platform Context 1.0.
- Decision Packet 2.0.
- Connected Decision Intelligence Platform and all prior governance, collaboration, publication, monitoring, and institutional integration behavior.

## v2.3.0 Energy runtime compatibility

This release is additive to **Decision Studio v2.3.0 — Energy Systems Runtime Consumer**. It preserves `backend/app/energy_runtime_consumer.py`, the `sc-energy-runtime-decision-studio-handoff/1.0` target contract, and the `/v1/energy-runtime/consumer` and `/v1/energy-runtime/consume` endpoints introduced for Energy Systems Intelligence v1.2.0. The Energy consumer remains versioned as 2.3.0 inside that component while the enclosing Decision Studio application advances to 2.3.1.
