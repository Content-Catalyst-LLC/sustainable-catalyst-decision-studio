# Decision Studio v2.7.0 — Site Intelligence Context Integration

Build fingerprint: `scds-v2.7.0-site-intelligence-context-integration`  
Source commit identity: `release-v2.7.0`

This release introduces typed Site Intelligence context bundles, immutable signal snapshots, context receipts, diagnostics for missing/fresh/stale metadata, explicit non-mutating scenario links, and Decision Object/Decision Packet projection.

New backend routes:

- `GET /site-intelligence-context/contracts`
- `GET /site-intelligence-context/template`
- `POST /site-intelligence-context/build`
- `POST /site-intelligence-context/validate`
- `POST /decision-object/site-intelligence-context`
- `POST /decision-packet/site-intelligence-context`

No signal is treated as a causal finding, probability, approval, or recommendation. Human review remains required.
