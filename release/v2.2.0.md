# Decision Studio v2.2.0 — Evidence & Source Bundles

Released: 2026-09-11

## Added

- `scds-source-bundle/1.0`
- `scds-evidence-bundle/1.0`
- `scds-evidence-coverage/1.0`
- deterministic source/evidence SHA-256 deduplication
- source-linked evidence records with citations, confidence, quality, freshness, limitations, provenance, and review status
- citation coverage, unresolved-source, review-gap, and contradiction diagnostics
- evidence-bundle merge support
- direct Evidence Bundle attachment to the Unified Decision Object
- additive Decision Packet evidence/source bundle projection
- WordPress **Evidence & Sources** workspace and REST parity
- Contabo-ready v2.2.0 runtime identity

## Preserved

- Decision Packet 2.0
- Unified Decision Object 1.0
- Platform Context 1.0
- v2.0.1 Catalyst module navigation/handoffs
- v2.0.0 Connected Decision Intelligence Platform
- all existing governance, publication, outcomes, API, accessibility, offline, and recovery features

## Boundary

The release can measure evidence organization and review state. It cannot automatically determine truth, professional sufficiency, legal admissibility, scientific validity, or approval readiness beyond the explicitly recorded review fields.
