# Decision Studio v3.0.0 — Connected Decision Intelligence

## Purpose
Unify the recorded Decision Studio lifecycle into **Frame → Evidence → Analyze → Compare → Stress → Review → Decide → Monitor**.

## Contracts
- `scds-connected-decision-intelligence/3.0`
- `scds-decision-lifecycle-state/1.0`
- `scds-decision-readiness-matrix/1.0`
- `scds-cross-product-route-plan/1.0`

## Boundary
Readiness is not approval. Lifecycle position is not an automatic transition. Route plans do not execute external work. Decision Studio does not select winners or authorize consequential action.
