# Decision Studio v3.7.0 — Narrative Risk Python Domain Migration

v3.7.0 promotes Narrative Risk from a registered module contract to an authoritative Python/PostgreSQL domain over the shared Decision Kernel and v3.4 repository. Canvas and Finance remain authoritative from v3.5/v3.6.

The domain normalizes claims/risk hypotheses, evidence links, and signals while keeping actors, exposures, competing narratives, watch conditions, mitigations, and provenance in the canonical domain object. Every normalized row is domain-tagged. Narrative Risk treats claims and signals as inspectable evidence-linked objects, not automatic truth or causality findings.
